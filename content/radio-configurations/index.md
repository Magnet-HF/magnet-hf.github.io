## Contribute the first model-specific guide

No model-specific radio configurations have been published in this library yet. We will index contributed guides by **manufacturer → model**, with links from the relevant tool pages.

A useful guide records the radio and firmware, computer platform, cables or interface, application versions, CAT/PTT and audio settings, verification steps, known issues, and the last test date.

[Submit a radio configuration](/contribute/) using the guide template. For a workflow that is not tied to one radio, see [operational guidance](/operational-guidance/).
