## Station checklist

1. Identify your radio, interface, cables, and computer platform.
2. Use each tool's download page to select the matching build. Read the technical guidance before installing.
3. Confirm your radio-control application can communicate with the radio.
4. Configure receive and transmit audio separately from CAT control.
5. Test one application at a time, then connect companion applications using their documented interfaces.
6. Record working versions and settings. Keep a copy before upgrading.
