## Technical guidance

**Currently suggested version: awaiting MagNet confirmation.** The publisher lists **2.2.14** as of October 23, 2026. This is a reference version, not a recorded MagNet station test.

Review the official manual for the [fldigi](/software/fldigi/) interface and transmit/receive configuration. Use matching workflow settings agreed with the receiving stations. [AMP-Express](/software/amp-express/) is an additional MagNet preparation utility.
