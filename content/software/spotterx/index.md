The dedicated SpotterX repository hosts releases and project documentation. The [original Mag-Windows release](https://github.com/Magnet-HF/Mag-Windows/releases/tag/SpotterX-v4.0) remains available.

## What it does

SpotterX works alongside JS8Call to organize received traffic and station activity. The published MagNet release describes station mapping, map pins, MCForms, offline mapping resources, and diagnostics. See the release notes for the capabilities included in a particular build.

## Technical guidance

**Currently suggested version: awaiting maintainer confirmation.** The existing MagNet release is tagged **SpotterX-v4.0**. This identifies the available package; station testing and compatibility with a specific JS8Call version have not been recorded here.

Requires a compatible JS8Call installation. The inspected package contains Python source, installation instructions, platform notes, and an upstream license notice. Follow the included MagNet installation guide, start JS8Call before SpotterX, and configure the TCP API connection as its README describes. Exact compatibility with the current MagNet Subspace build and bundled-form requirements still need developer confirmation.
