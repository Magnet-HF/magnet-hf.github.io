## Technical guidance

**Currently suggested version: awaiting MagNet confirmation.** The official download page lists **5.4**, published October 19, 2026. The older v4.x label on MagNet's website should not be interpreted as a tested-version recommendation.

The publisher provides a Python-based package for Windows, Linux, Mac, and Pi, plus platform-specific installation steps. Follow the prerequisite and installation instructions accompanying the chosen release.

Configure your callsign and station details, then configure the connection to JS8Call. Use **Config → Manage Groups** to add the MagNet groups described on the current [MagNet Tools page](https://magnethf.com/tools/): MAGNET, your MR01–MR10 region, and the appropriate region-plus-state group. The [Nets page](https://magnethf.com/nets/) provides the regional map.

Group configuration and a successful application connection should be confirmed before relying on displayed station status.
