## Technical guidance

**Currently suggested version: awaiting MagNet confirmation.** The official website advertises **16.1.8** as of October 23, 2026; this has not been station-tested for this library.

VarAC requires the VARA modem. The official prerequisite page covers Windows and Linux with Wine, modem requirements, and optional radio-control integrations. Obtain the application and modem through the official instructions.

MagNet uses VarAC for BBS file distribution. Obtain current BBS station details and operational procedures from MagNet before connecting. This library does not invent BBS addresses, schedules, or credentials.

[Contact MagNet for BBS setup guidance](https://magnethf.com/contact-us/).
